# SmartVault – Student Digital Locker

SmartVault is a modern student digital locker designed to keep important academic and personal documents organized in one secure location.

## Problem

Students keep documents across:

- Phone
- Email
- WhatsApp
- Physical files
- Different cloud storage platforms

This makes documents difficult to find and manage.

## Solution

SmartVault provides one digital locker where students can:

- Upload documents
- Organize documents
- Search documents
- Mark important documents
- View document details
- Delete documents
- Generate temporary sharing codes
- Store personal information
- View activity history
- Monitor security status

## Technologies

HTML5
CSS3
JavaScript

## Features

### Authentication

Student login and signup interface.

### Dashboard

Displays:

- Total documents
- Important documents
- Expiring documents
- Security status
- Recent activity

### Document Management

Supports:

- ID documents
- Marksheets
- Certificates
- Fee receipts
- Resume
- Other documents

### Smart Categorization

Documents are organized according to their selected category.

### Search

Students can quickly search their documents.

### Secure Sharing

The prototype generates temporary sharing codes for documents.

### Activity History

The application records recent actions such as:

- Login
- Upload
- View
- Delete
- Share
- Personal information updates
